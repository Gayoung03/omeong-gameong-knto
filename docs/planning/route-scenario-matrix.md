## 약점 3가지

1. **미충족은 전부 식사 슬롯이고 특정 조건에 집중** — 소형견 기준 빈 슬롯 5개가 모두 식당
   슬롯이며 **제주시 relaxed(1·2·3박)** 와 **동부(성산) packed 1박** 에 몰린다. 확실히 동반
   가능한 식당이 이 조합에서 부족하다.
2. **동부(성산) 권역이 가장 약하다** — 충족률 최저(0.95)·확인필요율 최고(0.037~0.048). 동부에
   확실 동반 식당·장소 밀도가 낮아 `needs_verification`·빈 슬롯이 이 권역에 집중된다.
3. **relaxed(여유) 속도가 확인필요·빈 슬롯 비율이 가장 높다** — 하루 슬롯 수가 적어 식사 슬롯
   비중이 커지고, 하나 못 채우면 충족률이 크게 떨어진다(0.935). 대형견은 빈 슬롯이 0 이지만
   확인필요율이 오르는데(0.016), 확실 후보가 없을 때 "확인 필요 식당"으로 슬롯을 메우기 때문이다.

## 재현

```bash
# 1) RDS(읽기전용) → 로컬 omeong_test 로 장소 복제
uv run python -m scripts.copy_places_for_measurement \
    --target-url postgresql+psycopg://omeong:omeong@localhost:5432/omeong_test
# 2) 측정 (--pets none|small|large)
uv run python -m scripts.measure_scenarios \
    --database-url postgresql+psycopg://omeong:omeong@localhost:5432/omeong_test \
    --pets small --json matrix_small.json
# 3) 측정 후 로컬 DB 원상복구(복제 장소 삭제)
uv run python -m scripts.copy_places_for_measurement \
    --target-url postgresql+psycopg://omeong:omeong@localhost:5432/omeong_test --truncate-only
```
