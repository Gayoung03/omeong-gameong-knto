# 반려동물 동반 이동 정보 수집표

작성일: 2026-08-26 · 담당: 율무 · 상태: **수집 중**

여행 가이드 콘텐츠(`guide_documents` 후보)의 원자료를 모으는 문서입니다.
**이 파일을 다 채우면 그대로 DB 씨앗 데이터가 됩니다.**

---

## 작업 순서

```
① 공식 페이지에서 표를 채운다     ← 지금 하는 것
② 표를 보고 '본문 초안'을 우리 문장으로 쓴다
③ 공통 항목이 눈에 보이면 테이블 컬럼을 정한다
④ 마이그레이션 + 씨앗 데이터
```

**③을 먼저 하지 않는다.** 테이블을 먼저 만들면 콘텐츠가 그 모양에 갇힙니다.
10개쯤 써보고 나서 정해야 안 맞는 컬럼이 안 생깁니다.

---

## ⚠️ 수집 규칙 — 이거 세 개만 지키면 됩니다

**1. 출처는 항공사 공식 홈페이지만.**
"항공사별 규정 총정리" 블로그는 언제 쓴 글인지 알 수 없고, 글마다 숫자가 다릅니다.
블로그는 *"어떤 항목을 봐야 하는지"* 참고용으로만 쓰고, **숫자는 반드시 공식 페이지에서** 가져옵니다.
우리가 틀린 숫자를 적으면 사용자가 공항에서 막힙니다.

**2. 원문을 보면서 본문을 쓰지 않습니다.**
사실(숫자·조건)에는 저작권이 없지만 **표현에는 있습니다.**
→ 표에 항목만 채운 뒤, **표만 보고** 본문을 씁니다. 그러면 자연스럽게 우리 글이 됩니다.

**3. 확인한 날짜를 반드시 적습니다.**
규정은 바뀝니다. 날짜가 없으면 나중에 이 값이 언제 것인지 아무도 모릅니다.

| 케이지 규격 | 보통 `가로+세로+높이 합` 또는 세 변 각각. 어느 방식인지 같이 적기 |

| **예약 없이 공항 방문** | ⭐ 아시아나에서 나온 항목. 사전 신청 없이 오면 아예 못 태우는 곳이 있습니다 |
| **공동운항편 제한** | ⭐ 코드셰어편은 실제 운항사가 달라 서비스가 안 될 수 있습니다 |
| 보조견 | 장애고객 보조견은 별도 규정 |
| **출처 URL** | 안내 페이지 주소 |
| **확인한 날짜** | 오늘 날짜 |

### 「추가로 나온 것」 칸을 따로 둡니다

**항공사마다 고유 항목이 나옵니다.** 대한항공에는 마일리지 결제와 SKYPETS 포인트가 있는데
다른 항공사엔 없을 가능성이 큽니다.

공통 표에 억지로 칸을 만들면 **대부분 빈칸인 열**이 생깁니다.
그래서 각 항공사 섹션 아래에 **자유 메모 칸**을 뒀습니다.

> 이게 나중에 테이블 설계에도 그대로 이어집니다 —
> **공통 컬럼(무게·요금·신청 시점) + `body` 마크다운(고유 항목)** 구조가 되는 이유입니다.

## ⚠️ 국내선만 골라냅니다

항공사 페이지는 국제선·국내선이 섞여 있습니다. **우리는 제주 = 국내선만** 필요합니다.

| 국제선 안내라 빼는 것 | 이유 |
| --- | --- |
| 광견병 예방접종증명서 · 검역증명서 | "목적지 **국가**가 요구하는 서류" — 제주는 국내 |
| 국제선 거리별 요금 | 우리 사용자는 안 씀 |
| 일부 국가 32kg 초과 제한 | 국내선과 무관 |

> ⚠️ 다만 **"국내선은 서류가 필요 없다"고 단정하지 마세요.** 확인한 뒤에 씁니다.
> 여기서 틀리면 사용자가 공항에서 헛걸음합니다.

---

## ⚠️ 건강 관련 내용의 경계선

항공사 페이지에는 급식·급수 안내가 섞여 있습니다. 이렇게 나눕니다.

| | 예 |
| --- | --- |
| ✅ **쓴다** — 항공사 운영 규칙 | "기내에서는 용기를 열지 않고 외부 급수장치로만 물을 줄 수 있어요" |
| ❌ **안 쓴다** — 건강 판단 | "출발 몇 시간 전에 얼마나 먹여라" |
| 대신 이렇게 | "식사 시점은 수의사와 상의하세요" |

항공사 원문에도 "수의사와 상의해주세요"라고 적혀 있습니다. **같은 선을 지키면 됩니다.**

---

## ⚠️ 용품 추천도 하지 않습니다

항공사 페이지에는 "이렇게 준비하세요"가 섞여 있습니다. **규정과 조언을 나눕니다.**

| | 예 |
| --- | --- |
| ✅ **쓴다** — 규정 | "대한항공은 높이 19cm, 아시아나는 21cm까지 가능해요" |
| ❌ **안 쓴다** — 구매 조언 | "19cm짜리 케이지를 사세요" |

**우리는 여행 플래너지 용품 가이드가 아닙니다.**
사용자가 *가지고 있는* 케이지가 되는지 판단할 재료만 주고, 고르는 건 사용자에게 맡깁니다.

> 건강 내용을 수의사에게 넘긴 것과 같은 원리입니다.
> **규정은 옮기고, 판단은 넘긴다.**

---

## ⚠️ 법령은 옮기지 않습니다

선사·항공사 페이지에 **동물보호법 안내**가 섞여 있는 경우가 있습니다.
(남해고속 「반려동물 동반승객 안전관리 지침」 — 목줄 2m, 물림사고 처벌 조항 등)

| | 예 |
| --- | --- |
| ✅ **쓴다** — 그 회사의 규정 | *"한일고속페리는 입마개·목줄 미지참 시 탑승 불가"* |
| ❌ **안 쓴다** — 법령 조문·처벌 규정 | *"공공장소에서 목줄 2m 이내"*, *"3년 이하 징역"* |

**세 가지 이유입니다.**

1. **선사 게시물은 법령의 공식 출처가 아닙니다.** 「수집 규칙 1」을 그대로 적용하면
   법령의 숫자는 **국가법령정보센터**에서 가져와야 합니다
2. ⚠️ **오래된 게시물이 많습니다.** 위 지침은 **2022년 7월** 게시물인데
   **동물보호법은 2023년에 개정**됐습니다. 현행인지 확인되지 않습니다
3. **법률 정보 제공은 우리 범위 밖입니다**

> **건강을 수의사에게 넘긴 것과 같은 원리입니다. 법률은 법령 원문과 기관에 넘깁니다.**
> 입마개·목줄을 지금도 쓰고 있지만, 그건 **법이라서가 아니라 그 선사의 탑승 조건이라서**입니다.
> 같은 물건이라도 **어느 자격으로 쓰는지**가 다릅니다.

## ⚠️ 원문이 애매할 때 — 어느 쪽으로 기우나

항공사 문장이 두 가지로 읽히는 경우가 반드시 나옵니다.
그때는 **"틀렸을 때 누가 손해를 보나"** 로 정합니다.

| 틀렸을 때 | 어떻게 |
| --- | --- |
| 사용자가 **못 간다고 믿고 안 감** (아쉽지만 안전) | **보수적으로 쓴다** |
| 사용자가 **된다고 믿고 갔다가 막힘** (여행 무산) | **쓰지 않는다.** 확인될 때까지 뺀다 |

**실제 사례 (아시아나)**

- **나이 16주** — 「기내 반입」 절에 나이가 없고, 다른 항목은 "위탁"을 구분해 쓰는데 나이만
  그냥 "운송 불가"라 **기내도 16주로 확정**. 틀려도 안전한 방향이라 채택했습니다.
- **A321 위탁** — `A321 (국제선 운송 불가)` 가 한정인지 부연인지 갈립니다.
  "된다"고 썼다가 틀리면 **대형견 보호자가 공항에서 막힙니다.**
  → **본문에서 뺐습니다.** 예약센터 답을 받은 뒤에 넣습니다.

> **애매하게 쓰느니 안 쓰는 게 낫습니다.** 빠진 정보는 사용자가 직접 찾아보지만,
> 틀린 정보는 그대로 믿습니다.

## ✅ 결정 — 기종 제한은 이렇게 씁니다 (2026-08-26)

기종 얘기가 세 곳 모두에서 나왔는데 **표기 방식이 제각각이고 대부분 읽기가 갈립니다.**
게다가 사용자가 예약할 때 기종을 확인하는 것 자체가 어렵습니다.

**기본** — 본문에 이 한 줄로 통일합니다.

```
기종에 따라 위탁이 제한될 수 있으니, 예약할 때 항공사에 확인해 주세요.
```

**예외** — **항공사가 명확히 밝힌 것은 그대로 씁니다.**

| 항공사 | 표기 | 처리 |
| --- | --- | --- |
| 대한항공 | 737·A321 **국내선 혹서기(6~9월)** 위탁 제한 | ✅ **그대로 쓴다** — 범위가 명확 |
| 아시아나 | `A321 (국제선 운송 불가)` | 통일 문구로 |
| 진에어 | 위탁 기종에 `B777` 만 표기 | 통일 문구로 |

> **애매한 걸 안 쓰는 것과 확실한 걸 안 쓰는 것은 다릅니다.**
> 통일은 읽기가 갈리는 것에만 적용하고, 항공사가 분명히 알려준 정보는 살립니다.
> 대한항공 6~9월은 **제주 성수기 + 대형견 위탁**이라 실제로 걸리는 사람이 있습니다.

**부수효과** — 문의 2건(아시아나 A321 · 진에어 B777)이 **더 이상 진행을 막지 않습니다.**
통일 문구로 본문을 완성할 수 있고, 나중에 답이 오면 그때 명확한 문장으로 바꿉니다.
**표에는 원문 표기를 그대로 남겨둡니다** — 근거이고, 답이 왔을 때 대조할 기준입니다.

## 작성 예시

> 아래는 **형식을 보여주기 위한 가상의 예시**입니다. 숫자는 실제 값이 아닙니다.

### ○○항공

- 출처: `https://example.com/pet-guide`
- 확인일: 2026-08-26

| 항목 | 값 |
| --- | --- |
| 기내 반입 | 가능 |
| 무게 상한 | **케이지 포함** 7kg 이하 |
| 케이지 규격 | 세 변 합 100cm 이내 |
| 케이지 조건 | 잠금장치 필수, 천장 개폐형 불가 |
| 동반 가능 동물 | 개·고양이 (단두종 제한 있음) |
| 나이 제한 | 생후 8주 이상 |
| 요금 | 국내선 편도 20,000원 |
| 사전 신청 | 필요 · 출발 24시간 전까지 |
| 편당 마릿수 | 최대 5마리 |
| 케이지당 마릿수 | 1마리 |
| 화물칸 위탁 | 가능 · 32kg 이하 |
| 예외·거절 | 임신·질병 시 탑승 불가 |

**본문 초안** ← 위 표만 보고 쓴 우리 문장

```
○○항공은 케이지를 포함해 7kg 이하면 기내에 함께 탈 수 있어요.
케이지는 세 변의 합이 100cm 이내여야 하고, 잠금장치가 있어야 합니다.
출발 24시간 전까지 미리 신청하셔야 하고, 한 편에 5마리까지만 탈 수 있어
성수기에는 일찍 마감될 수 있어요.

2026년 8월 기준이며 규정이 바뀔 수 있으니 탑승 전 확인해 주세요.
```

> 본문은 **5~10줄**이면 충분합니다. 표를 그대로 옮겨 적는 게 아니라,
> **보호자가 실제로 걸리는 것**(무게 기준, 미리 신청, 마릿수 제한)을 골라서 씁니다.

## 이 표에서 나온 것

**① ⭐⭐ 제주항공은 화물칸 위탁 자체가 없습니다.**

> *"반려동물 운송서비스는 기내 반입만 가능하고 위탁 수하물로 탑재할 수 없습니다."*

**9kg를 넘으면 제주항공으로는 갈 방법이 없습니다.** 다른 세 곳은 무거우면 화물칸이라는
선택지라도 있는데, 제주항공은 그 선택지가 아예 없습니다.

이름이 "제주"항공이라 제주 여행에 제일 먼저 떠올리는 곳인데,
**대형견 보호자에게는 오히려 못 쓰는 항공사**라는 뜻입니다. 반드시 알려야 합니다.

**② ⭐ 몸무게에 따라 갈 수 있는 항공사가 갈립니다.**

| 케이지 포함 무게 | 갈 수 있는 방법 | 선택지 |
| --- | --- | --- |
| ~7kg | **일곱 곳 모두 기내** | 7곳 |
| 7~9kg | 진에어·제주항공·티웨이·에어부산·이스타 **기내**<br>대한항공·아시아나는 **화물칸** | 7곳 |
| 9~32kg | 대한항공·아시아나·진에어·에어부산 **화물칸**<br>제주항공·티웨이·이스타 **불가** | **4곳** |
| **32~45kg** | 대한항공·아시아나·진에어 **화물칸**<br>에어부산도 **불가**(32kg 상한) | **3곳** |
| 45kg 초과 | **항공기로는 불가** → 여객선(8번 문서) | **0곳** |

`pets.weight_kg` 가 DB에 있으니, 나중에 챗봇이 **등록된 몸무게로 갈 수 있는 항공사를 골라줄 수**
있습니다. **이 표가 그대로 챗봇 답변이 됩니다.**

> ⚠️ **무거워질수록 선택지가 계단식으로 줄어듭니다.** 32kg를 넘으면 여섯 곳 중 셋만 남고,
> 그 셋 중 둘은 기종 제한이 미확정입니다. **대형견은 여객선을 함께 안내해야 합니다.**

**③ ⚠️ "저비용항공사가 싸다"가 성립하지 않습니다.**

| | 기내 요금 |
| --- | --- |
| 진에어 | 20,000원 |
| 제주항공 | 25,000원 |
| **티웨이** | **30,000원** |
| 대한항공·아시아나 | 30,000원 |

**티웨이는 대형항공사와 같은 금액인데 위탁은 안 됩니다.** 뭉뚱그려 쓰면 틀리니
**항공사별 금액을 그대로** 적습니다.

반면 **위탁 요금은 되는 세 곳이 똑같습니다** (30,000 / 60,000원).
위탁만 업계 표준이 있는 모양입니다.

**④ 케이지 규격이 항공사마다 다르고, 표기 방식까지 제각각입니다.**

- 대한항공·아시아나 — 가로 32 × 세로 45 × 높이 (19cm / 21cm)
- 진에어 — **삼면의 합 115cm**, 높이 20cm
- 제주항공 — **삼면의 합 100cm + 가로 37cm + 높이 23cm** (조건 세 개)

**네 곳이 네 가지 방식으로 적고 있습니다.** 같은 케이지가 한 항공사에서는 되고 다른 곳에서는
안 될 수 있고, 표기 방식이 달라 단순 비교도 안 됩니다.
→ 본문에는 **항공사별로 따로** 적습니다. 합치려 하지 않습니다.

> ⚠️ **여기서 선을 긋습니다.** 우리는 *"항공사별 규격이 이렇습니다"* 까지만 씁니다.
> *"이런 케이지를 사세요"* 는 쓰지 않습니다 — 용품 추천은 이 앱이 할 일이 아닙니다.
> 사용자가 **가지고 있는 케이지가 되는지** 판단할 재료만 주면 됩니다.

**⑤ 나이 기준이 다릅니다.**
대한항공·진에어·제주항공·티웨이는 기내 8주인데 아시아나만 **기내도 16주**입니다.
어린 강아지와 가는 보호자에게는 항공사 선택이 갈리는 지점입니다.

**⑥ ⚠️ "저비용항공사 공통 패턴"은 반만 맞았습니다 — 성급했던 판단**

| | 위탁 | 서약서 | 온라인 체크인 |
| --- | --- | --- | --- |
| 대한항공·아시아나 | 가능 | (명시 없음) | (명시 없음) |
| 진에어 | 가능(미확정) | **필요** | **불가** |
| 제주항공 | **불가** | **필요** | **불가** |
| 티웨이 | **불가** | **필요** | **불가** |
| **에어부산** | **가능** (32kg) | **필요** | (명시 없음) |

**공통인 것은 「서약서 필요」 하나뿐입니다.** LCC 4곳 모두 요구합니다.

- **위탁** — LCC 안에서도 갈립니다. 제주항공·티웨이는 불가, 진에어·에어부산은 가능
- **온라인 체크인** — 3곳은 불가라고 명시했지만 에어부산은 언급이 없습니다.
  **"없다"가 "가능하다"는 아닙니다** → 확인 안 됨으로 둡니다

> **세 개를 보고 패턴이라 부른 것이 일렀습니다.** 네 번째에서 깨졌습니다.
> 표본이 적을 때 "대체로 이렇다"고 쓰면, 예외인 항공사를 타는 사용자가 손해를 봅니다.
> → **본문에는 항공사별 값을 그대로 적고, 묶어 쓰지 않습니다.**

**⑦ ⭐ 준비 없이 가도 되는 곳과 그렇지 않은 곳이 갈립니다.**

| | 예약 없이 공항에 가면 | 케이지 없으면 |

> 💡 **공항 판매 케이지는 그 항공사 규격에 맞춰 만들어져 있습니다.**
> 에어부산 것은 41×21×24cm로 자사 상한과 정확히 일치하고,
> 티웨이 것도 37×22×23cm로 하드케이스 기준에 맞춰져 있습니다.
> **다른 항공사에서도 통과한다는 보장은 없습니다** — 왕복 항공사가 다르면 주의해야 합니다.

**티웨이는 아무 준비 없이 공항에 가도 되는 유일한 항공사입니다.**
아시아나와 정확히 반대편이에요. *"급하게 가야 하는데 아무것도 준비 못 했다"* 는
상황에서 우리 앱이 줄 수 있는 가장 실질적인 답입니다.

**⑧ 맹견·단두종 목록이 항공사마다 다릅니다.**
대한항공 8종 / 아시아나 12종 / 진에어 10종 / **제주항공 15종** / 에어부산 12종.
**티웨이(3종)와 이스타(4종)는 예시만 있고 전체 목록이 없습니다.**

> 💡 **에어부산 목록은 아시아나와 완전히 같습니다** — 같은 계열사라서요.
> 계열 관계를 알면 확인 시간을 줄일 수 있습니다.

**⑨ ⭐ 단두종 제한도 위탁 유무에 묶여 있습니다.**

단두종(퍼그·시추·불독 등)을 막는 건 **위탁을 받는 항공사뿐**입니다.
제주항공·티웨이·이스타는 국내선에서 단두종 제한이 없습니다 — **위탁 자체가 없으니까요.**

> **역설적인 결과입니다.** 단두종 보호자에게는 *"위탁을 안 하는 항공사"* 가 오히려 편합니다.
> 다만 9kg 안에 들어와야 한다는 조건은 그대로입니다.
**"맹견 목록"을 하나로 합치면 안 됩니다.** 항공사별로 따로 들고 있어야 합니다.

> 진에어 목록에는 **영문 병기**와 별칭(오브차카=코카시안 셰퍼드 독, 캉갈=아나톨리언 셰퍼드 독)이
> 있어 셋 중 가장 정확합니다. `pets.breed` 와 대조할 때 이 목록을 기준으로 삼는 게 좋겠습니다.

**⑩ 기종 제한은 대부분 애매합니다. → 처리 방식 결정됨**

### ⚠️⚠️ boolean은 반드시 nullable — `NOT NULL DEFAULT false` 금지

문서가 「불가」와 **「(명시 없음)」** 을 처음부터 끝까지 구분해 왔습니다.

> *"**"없다"가 "가능하다"는 아닙니다** → 확인 안 됨으로 둡니다"* (에어부산 온라인 체크인)

`false`로 뭉개면 **"확인 안 됨"이 "불가"로 바뀝니다.**
그러면 챗봇이 *"에어부산은 온라인 체크인이 안 됩니다"* 라고 **없는 규정을 만들어 답합니다.**

| 값 | 뜻 |
| --- | --- |
| `true` | 가능하다고 명시됨 |
| `false` | **불가라고 명시됨** |
| `null` | **확인 안 됨** ← 챗봇은 "확인이 필요해요"라고 답해야 합니다 |

**이 문서 전체를 관통하는 원칙이 스키마에서는 이 한 줄로 나타납니다.**

### ⭐ `is_example_only` 가 필요한 이유

티웨이는 **3종**, 이스타는 **4종**만 예시로 들었고 전체 목록이 없습니다.
이걸 다른 항공사 목록과 같은 테이블에 그냥 넣으면, 챗봇이
*"티웨이 맹견은 이 3종입니다"* 라고 **없는 확정을 만들어 답합니다.**

→ `is_example_only = true` 면 챗봇은 **"지정 견종이 있으니 예약 시 확인하세요"** 로 답합니다.
문서가 *"우리가 목록을 채워 넣으면 안 됩니다"* 라고 정한 판단을 **스키마가 강제하는 장치**입니다.

> ⚠️ **항공사별 목록을 하나로 합치면 안 됩니다.**
> 대한항공 8 · 아시아나 12 · 진에어 10 · 제주항공 15 · 에어부산 12 — 전부 다르고,
> **도베르만은 제주항공에만** 있습니다. `transport_rule_id` 로 항공사에 묶어 둡니다.
