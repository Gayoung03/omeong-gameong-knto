# 명소 큐레이션 데이터 (`landmarks.json`)

작성일: 2026-09-08 · 작성: viowlet · 근거: 재설계 Phase 2 ([`docs/planning/route-redesign.md`](../../../../../docs/planning/route-redesign.md), 이슈 #268)

루트 추천은 **확실히 동반 가능한 곳만** 기본 후보로 쓴다(재설계 D3). 그래서 이 파일은 두 종류를 담는다.

1. **동반 가능 명소** — 관리 주체나 관광공사가 동반 가능을 명시한 곳만 (18곳)
2. **동반 금지 명소** — 사용자가 흔히 떠올리는 대표 명소 중 공식 안내로 금지가 확인된 곳 (10곳).
   추천 후보에서는 빠지지만, 챗봇·검색이 "여기는 안 됩니다"를 근거와 함께 답할 수 있게 등록한다.

## 원칙

- **근거 URL 없이는 등록하지 않는다.** `pet_policy.source_url` 이 관리 주체 공식 페이지(제주도청·세계유산본부·비짓제주·서귀포시)이거나 한국관광공사 반려동물 동반여행 등록 페이지여야 한다.
- 관광공사 TourAPI(`KorPetTourService2`)는 **탐색용으로만** 썼다. 응답을 저장하지 않고, 등록 행의 출처는 관광공사 웹 페이지 URL 이다(팀 규칙: TourAPI 응답 적재 금지).
- 국립공원·세계자연유산·도립공원·국공립 휴양림·유료 폭포는 원칙적으로 금지다. 공식 문구를 찾은 곳만 `not_allowed` 로 넣었고, 못 찾은 곳은 아래 "전화 확인 목록"에 남겼다.
- 좌표는 카카오 지오코딩(주소·장소명 유도 좌표, 저장 허용). 산방산은 동명의 거제 산방산으로 잡혀 직접 입력했다.
- `verified_at` 은 근거를 확인한 날이다. 정책은 바뀌므로 시연 전 재확인한다.

## 후속

- 해수욕장은 개장 기간(7~8월)에 유영구역 출입 금지·목줄 필수. 정책 notes 에 이미 있으나 추천 규칙에 "개장 기간 해변 체류 짧게"를 넣을지 Phase 5에서 검토.
- 관광공사 반려동물 API 의 제주 관광지는 20곳뿐이라 오름·해안 명소의 상당수는 여전히 근거가 없다. 다음 배치는 제주도 오름탐방 GIS(gis.jeju.go.kr/jejuoreum)와 비짓제주 상세 페이지의 "반려동물 동반" 필드를 대상으로 한다.
