# 여행기록 카드 손글씨 폰트

여행기록 카드(`travel_logs`)를 합성할 때 사진 위에 얹는 손글씨 폰트다.
말투(`writing_style`)에 따라 다른 폰트를 쓴다 — 말투를 바꾸면 글씨체까지 바뀌어야
사용자가 다른 결과물이라고 느낀다.

| 파일 | 쓰는 곳 | 서체 |
| --- | --- | --- |
| `jeju-hallasan.ttf` | `writing_style = jeju_dialect` | 제주한라산체 |
| `gaegu-regular.ttf` | `writing_style = dog_diary` | 개구 (Gaegu) Regular |

## 라이선스

**둘 다 상업적 이용·변형·재배포가 허용된다.** 저장소와 Docker 이미지에 포함해도 된다.

### 제주한라산체 — 공공누리 제1유형 (출처표시)

```
제주한라산체 / 제주특별자치도
https://www.jeju.go.kr/jeju/symbol/font/infor.htm
https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?wrtSn=13287189&menuNo=200026
KOGL 출처표시 — 상업적·비상업적 이용 가능, 변형 등 2차적 저작물 작성 가능
```

배포처의 "유료로 양도하거나 판매하는 등 상업적 행위는 금지" 문구는 **폰트 파일 자체를
판매하지 말라**는 뜻이다. 폰트로 만든 결과물의 상업적 이용은 공공누리 제1유형이 명시적으로
허용한다(위 라이선스 배지 원문). 원문은 `KOGL-JejuHallasan.txt`.

**출처 표시가 의무다.** 공모전 제출물·앱 오픈소스 고지에 위 3줄을 넣는다.

### 개구 (Gaegu) — SIL Open Font License 1.1

```
Gaegu / Hyun-Seung Lee (이현승)
https://fonts.google.com/specimen/Gaegu
SIL Open Font License 1.1
```

원문은 `OFL-Gaegu.txt`. OFL은 재배포를 명시적으로 허용하며 조건은 두 가지다 —
폰트 파일만 따로 떼어 판매하지 않을 것, 라이선스 원문을 함께 둘 것. 둘 다 지키고 있다.

## 글리프 커버리지 (2026-09-07 실측)

| 폰트 | 현대 한글 음절 | 옛한글 자모 |
| --- | --- | --- |
| 제주한라산체 | **11,172 / 11,172 (100%)** | 없음 |
| 개구 | 2,350 (KS X 1001 완성형) | 없음 |

개구의 2,350자는 실사용 한국어를 전부 덮는다. 반려동물 이름 30종·강아지 말투 어미
16종을 검사해 빠진 글자가 없었다. 유니코드 음절 11,172자 중 8할이 없지만 그것들은
`쒧`·`웪` 같은 실제로 쓰이지 않는 조합이다.

**다만 둘 다 옛한글(아래아)이 없다.** `ᄒᆞ르`·`ᄆᆞᆯ` 같은 제주어 고어 표기는 두부(□)로
그려진다. 그래서 두 가지를 건다.

1. 문구 생성 프롬프트에서 **아래아·옛한글 표기를 금지**한다 (현대 한글로만).
2. 합성 직전에 **폰트에 없는 글자가 있는지 검사**하고, 있으면 그 문구를 버리고 다음 후보를 쓴다.

## 파일명을 영문으로 바꾼 이유

원본은 `JejuHallasan.ttf`·`Gaegu-Regular.ttf`였고 배포 zip 안쪽 이름은 한글(CP949)이었다.
저장소 규칙(소문자+하이픈)에 맞추고, 한글 경로가 인코딩 오류를 내는 사고를 이미 겪었기
때문에(`README` 개발환경 절의 CocoaPods 건) 경로에 한글을 두지 않는다.

## Docker

`Dockerfile` 의 `COPY assets ./assets` 로 이미지에 들어간다. 코드에서는
`app/services/card_render.py` 가 `assets/fonts/` 를 기준 경로로 읽는다.
